# BinaryScope

A small, read-only command-line utility for inspecting local binary files.

## Features
- Reports file size and a short hexadecimal header preview.
- Detects a few common file signatures (PNG, JPEG, GIF, PDF, ZIP).
- Does not modify files or execute their contents.
- Uses only the Python standard library.

## Usage
```bash
python binaryscope.py path/to/file
```
